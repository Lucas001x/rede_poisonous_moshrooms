# 🍄 **Classificação de Cogumelos - Rede Neural Binária**

## 📖 Sobre o Projeto
Este projeto implementa uma **rede neural binária** utilizando **Keras e TensorFlow** para classificar cogumelos como **comestíveis ou venenosos**, com base em um conjunto de **dados tabulares** contendo características físicas e químicas.

O objetivo é explorar **aprendizado supervisionado** e redes neurais para resolver um problema de classificação binária. O modelo é treinado com um conjunto de dados contendo atributos como **cor, formato do chapéu, textura do caule, presença de anel, cor das lamelas**, entre outros.

Essa abordagem pode ser útil para estudos em **botânica, segurança alimentar e biologia computacional**, além de servir como uma base para entender redes neurais aplicadas a dados estruturados.

---

## ✨ Funcionalidades
✔️ **Classificação automática** de cogumelos entre comestíveis e venenosos  
✔️ **Modelo baseado em redes neurais binárias** treinado com TensorFlow/Keras  
✔️ **Pré-processamento de dados categóricos e numéricos**  
✔️ **Treinamento e validação** com divisão de dataset  
✔️ **Análise de métricas** como acurácia, precisão e recall  
✔️ **Gráficos de aprendizado** para visualizar a evolução do modelo  
✔️ **Possibilidade de entrada de novos dados** para predição  

---

## 🛠 Tecnologias Utilizadas
Este projeto utiliza um conjunto de ferramentas para manipulação e análise de dados, além do treinamento da rede neural:

- **Python** → Linguagem principal para desenvolvimento  
- **Pandas & NumPy** → Manipulação de dados tabulares  
- **Scikit-Learn** → Pré-processamento de dados e métricas de avaliação  
- **TensorFlow/Keras** → Construção e treinamento do modelo de rede neural  
- **Matplotlib & Seaborn** → Visualização dos resultados
